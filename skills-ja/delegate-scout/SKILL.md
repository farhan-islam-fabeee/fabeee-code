# scout への委任

1. `subagent` ツールを `scout` エージェントで呼ぶ。1回の呼び出しにつき質問は1つとし、検索対象のディレクトリも渡す。
2. タスクの最後に必ず次の一文を付ける: *「300字以内で答えること: 主要なファイル(file:line 付き)、それらのつながり、未解決の疑問。コードの貼り付けは不要。」*
3. scout の同時実行は最大2つまで。
4. 要約を信頼する。開くのは編集する予定の `file:line` 参照1〜3件だけにし、`lean-read` を使う。
