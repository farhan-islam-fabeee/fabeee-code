# ドキュメント参照

1. **まずメモを確認する。** `.pi/notes/<library>.md` があり、バージョンが一致していればそれを使い、Context7 は呼ばない。
2. **インストール済みのバージョンを調べる**(`npm ls <pkg> --depth=0`、`pip show <pkg>`、またはマニフェスト)。ロックファイルは読まない。
3. **狭く問い合わせる。** ライブラリ ID の解決は1回だけ行い、具体的なトピックを1つに絞って問い合わせる(例: "middleware"、"useQuery options")。トークン量は、答えが得られる範囲で最小(約2000)を指定する。
4. **頼りにする内容を保存する。** `.pi/notes/<library>.md` に30行以内で書き、1行目にバージョンを記す。次に必要になったら Context7 を呼ばずにそのファイルを読む。
